# Changelog

All notable changes to LexUK are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [Semantic Versioning](https://semver.org/), applied to a skill as described in [CONTRIBUTING.md](CONTRIBUTING.md#versioning).

Legal content can go out of date without any change to this file. The date of a version is the date the files were last edited, not a guarantee that the law described is still current. LexUK re-verifies the law live in every conversation.

## [Unreleased]

## [1.0.0] - 2026-10-09

First public release.

### Added

- LexUK skill for e-commerce, online platform and data protection compliance in the United Kingdom, including the UK-EU interface (selling into the EU, Northern Ireland under the Windsor Framework, UK-EU data flows).
- Workflow: classification, prioritised intake, hidden-domain detection, live verification on official sources, answers with confidence levels, escalation to the right specialist.
- Reference files for consumer law, platforms, products and imports, data protection, cookies and marketing, tax, payments, security, AI and data, IP, competition and advertising, and the UK-EU interface.
- Acts registry as a starting map, with a few fast-moving items spot-checked against secondary sources in October 2026.
- `dist/lexuk.skill` package for the Claude app, and one-command installers for Claude Code (`install.sh`, `install.ps1`).
- License: Apache License 2.0 with the Commons Clause condition.
- Contributor guide, issue templates (legal inaccuracy, coverage request, bug report) and a local CI script (`scripts/ci.sh`).
